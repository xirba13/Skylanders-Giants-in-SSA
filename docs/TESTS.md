# Tests

All tests run through Dolphin's Riivolution support, so the disc image is never modified.
Build them and install the patch for playing with `python tools/build_tests.py --install`: the newest Giants test
(test 41), shown in Riivolution as **Skylanders Giants port > Giants** (`riivolution/GiantsPort.xml`, files in
`giants-port/` laid out like the disc). `--install-tests` installs every test below instead, as **Giants port
tests > Test** (`riivolution/GiantsPortTests.xml`, files in `giants-port-tests/`).

## Setup (once)

1. Spyro's Adventure (your own PAL disc image, see the README) is in Dolphin's game list.
2. Figures, in **Tools > Skylanders Portal**: a Spyro, and the Giants (**Create** makes new ones; to use a dump
   of a figure you own, load a copy so the original stays untouched). Use **Load** to put one on the portal.
3. File log, needed for tests 5 and 6: **View > Show Log Configuration**. Set Verbosity to **Info**, tick
   **Write to File**, and in the list tick **File Monitor**. Dolphin then writes every disc file the game opens to
   `%APPDATA%\Dolphin Emulator\Logs\dolphin.log`, which the tools can read.

## Running a test

1. Right-click Skylanders: Spyro's Adventure > **Start with Riivolution Patches...**
2. Under **Giants port tests**, set **Test** to the test (installed with `--install-tests`), then **Start**. The
   patch for playing is **Skylanders Giants port**: set **Giants** to **Enabled**.
3. Tests 1, 4a, 4b: load a save, place Spyro, play a level briefly.
   Tests 5-12: load a save, place Spyro first and check it works, then remove it and place Tree Rex (test 12:
   the Giant figures; create them in the Skylanders Portal window with Create, or use copies of dumps).
   Test 34: also the variant figures (copies of their dumps, or Create with e.g. "Gnarly Tree Rex"); a variant
   is told apart from its base Giant only by the variant word of its block 1.
   Test 41: before starting, set the language in **Config > Wii > System Language** (English, French, Dutch,
   German, Italian or Spanish); Spyro's Adventure follows the console language.
4. Close the game before switching to another test.

## On a real Wii

The patch for playing works through Riivolution on a Wii with the Homebrew Channel (the app in
`SD:/apps/riivolution/`). `python tools/build_tests.py --no-build --sd E:\` installs it on a FAT32 SD card from the
last build, as in Dolphin's `Load/Riivolution` folder: `riivolution/GiantsPort.xml` and `giants-port/` (55 files,
about 520 MB; files that did not change are not copied again). Riivolution needs the disc, and it does not boot the
Virtual Portal's alternate DOL, so use the real portal there. (Works on a real Wii, 2026-10-06.)

Choose the language in **Wii Settings > Language**, start Riivolution from the Homebrew Channel, set **Skylanders
Giants port > Giants** to **Enabled** and launch. Install again after every rebuild.

Without Riivolution (USB Loader GX, any Game IOS): `python tools/bake_image.py` writes the patch into a copy of the
extracted disc, `build/image/SSPP52` (59 files replaced or added, and the memory value written into
`sys/main.dol` at file offset 0x4910CC), and with Wiimms ISO Tools installed builds `build/image/SSPP52.wbfs`.
Dolphin can run either without the Riivolution patch.

A loader set to boot an alternate DOL (the Skylanders Virtual Portal boots `sd:/SSPP52.dol`) ignores the image's
`main.dol` and with it the character memory patch: the Giants then stay on the element screen, as in test 13
(found on a real Wii, 2026-10-06). `python tools/bake_image.py --patch-dol IN.dol OUT.dol` writes the patch into
that DOL; the Virtual Portal's leaves the patched word alone (its own changes are a section at 0x80001800 and five
hooks), so the result differs from it by one byte.

On real hardware the game writes to the real figures: so far
every Dolphin figure shows Spyro's Adventure writing only its own save blocks (8-16 and 36-44), never the blocks
where later games keep their data (17-21 and 45-49).

## What to record

- Did the game boot, and did the character appear? For tests 5 and 6: what happened when Tree Rex was placed
  (Spyro appeared, a "not compatible" style message, nothing, a crash)?
- Crash or freeze: when, and the full text of any Dolphin error box.
- Nothing else is needed for the file log; it is read from `dolphin.log`.
